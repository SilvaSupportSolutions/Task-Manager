# Task Manager

Task management application focused on productivity, organization and workflow control.

## About the project

This project was created to practice JavaScript fundamentals, DOM manipulation and LocalStorage.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- Save tasks using LocalStorage

## Technologies

- HTML5
- CSS3
- JavaScript

## How to run

Open the `index.html` file in your browser.

## Project purpose

This project is part of my front-end learning path while studying Systems Analysis and Development.
